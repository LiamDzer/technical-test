## Tech Stack

Project ini dibuat menggunakan React dengan TypeScript sebagai bahasa pemrograman utama, Vite sebagai build tool dan development server, Bootstrap untuk membantu pembuatan layout dan komponen, serta CSS untuk styling dan responsive design.


## Cara Menjalankan Project

1. Clone repository
   git clone https://github.com/LiamDzer/technical-test.git

2. Masuk ke folder project
   cd technical-test

3. Install dependencies
   npm install

4. Jalankan project
   npm run dev

5. Buka alamat yang ditampilkan di terminal, biasanya:
   http://localhost:5173
